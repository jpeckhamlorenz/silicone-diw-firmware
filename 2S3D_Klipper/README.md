# Key Files for Klipper Firmware for 2S3D Printer

This folder stores key files, like printer configurations or custom scripts, that will be version controlled. The files **directly** from relevant official repositories will **not** be included here, unless they are *to be customized* in the future.

There will also be bash scripts (intended to run on **Raspberry Pi host**) that checks the differences for the actual files and the tracked ones in the repo, and either deploy them to Raspberry Pi or update files in repo.

## Klipper Structure on Host

Relevant folders on the host Raspberry Pi is shown below:

```bash
silicone-diw@2S3D-Klipper:~ $ ls
kiauh  klipper  klippy-env  printer_data
```
